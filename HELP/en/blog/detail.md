# Blog Management: Edit and Detail

This page allows you to manage the content of a blog post in detail.

---

## ✍️ Editor Usage

### Content Area
Use the rich text editor to add:
- **Hierarchical Headings (H1-H4)**
- **Images and Media**
- **Ordered/Unordered Lists**
- **Code Blocks and blockquotes**

### Side Panel Settings
- **SEO Settings:** Fill out Meta Title and Description for Google visibility.
- **Category Selection:** Choose where the post will be grouped.
- **Featured Image:** Upload the cover image for list pages.

---

## 🚦 Saving and Publishing
After making changes:
1. **Choose Status:** (Published / Draft / Hidden)
2. **Save:** Press the button in the top right to send changes to the server.
