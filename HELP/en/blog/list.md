# Blog Management: List View

This page allows you to manage all blog posts in the system in a general table format.

---

## 🔍 List Features

### Filtering and Searching
- **Search Bar:** Quick search by title.
- **Status Filter:** Filter only "Draft" or "Published" posts.
- **Bulk Actions:** Select multiple posts to update their status or delete them.

### Table Columns
- **Image:** Cover image of the post (Default icon if none).
- **Title:** Visible name of the post.
- **Category:** Main and sub-categories the post is linked to.
- **Status:** Publication status of the post.

---

## ⚡ Quick Actions
- Click a row in the table to go to the **Detail/Edit** page.
- Use the **"New"** button in the top right to start creating new content.
