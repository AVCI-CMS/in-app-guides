# Brand Management: List View

This page allows you to manage creative brands, artists, and boutique manufacturers across the platform.

---

## 🔍 Brand Identity Oversight

### List Features
- **Category Filtering:** Group brands by art discipline or production type.
- **Ownership:** Instantly see which user manages which brand.
- **Search:** Quickly access brands via their display name.

### Table Columns
- **Logo:** Visual branding of the creator.
- **Brand Name:** Trading or artistic name.
- **Owner:** The individual from members managing the brand.
- **Techniques:** Skills of the brand (e.g., Glass Blowing, Weaving).
- **Status:** Current visibility state.

---

## ⚡ Quick Actions
- Click a row to edit brand profiles, assign team members, or pin locations.
- Use the **"New Brand"** button in the top right to start a new entry.
