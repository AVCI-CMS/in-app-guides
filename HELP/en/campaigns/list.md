# Campaign Management: List View

This page allows you to manage all discount periods, seasonal campaigns, and marketing activities across the platform.

---

## 🔍 Promotional Oversight

### List Features
- **Active State:** Filter by live, expired, or paused campaigns.
- **Date Range:** Monitor campaign start and end times directly from the panel.
- **Featured:** Define which campaigns appear as banners on the main page.

### Table Columns
- **Campaign Name:** Title of the promotion.
- **Discount:** Percentage or Fixed amount.
- **Start/End:** Validity period of the campaign.
- **Status:** Active, Inactive, or Expired.

---

## ⚡ Quick Actions
- Click a row to edit campaign details (conditions and product mappings).
- Use the **"New Campaign"** button in the top right to start a new entry.
