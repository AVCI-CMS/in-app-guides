# Communication Management: List View

This page allows you to centrally manage all customer messages and inquiries coming through your website's contact forms.

---

## 🔍 Incoming Message Oversight

### List Features
- **Read/Unread Toggle:** Filter only "Unread" messages to respond quickly.
- **Subject Categories:** Separate partnership, technical support, or general inquiries.
- **Customer Contact:** Instantly access the phone number and e-mail of the sender.

### Table Columns
- **Sender:** Name and Surname.
- **Subject:** Inquiry headline.
- **Date:** Reception time.
- **Status:** Unread, Read, or Responded.

---

## ⚡ Quick Actions
- Click a row to see the full message content and write a response.
- **Respond:** Send an email directly to the customer to finalize the inquiry.
- **Archive:** Clean up the list by moving processed messages to the archive.
