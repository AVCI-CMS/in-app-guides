# Coupon Management: Detail and Constraints

Configure the logic, valid products, and usage limits of your discount code.

---

## 🛠️ Coupon Configuration

### Definition and Value
- **Coupon Code:** Unique alphanumeric key (e.g., `SUMMERGIFT`).
- **Discount Value:** How much discount to apply (e.g., $10 or 15%).
- **Min Order Amount:** The subtotal limit required to activate the coupon.

### Usage Limits
- **Total Usage:** How many times this coupon can be used globally (e.g., First 100 people).
- **Usage Per Person:** Max number of times a single customer can use this code.
- **Product/Category Restriction:** Ensure the coupon only applies to specific collections.

---

## 🚦 Activation
Once a coupon is set to **"Active"** (and within its date range), customers can start using it on the checkout page.
