# Coupon Management: List View

This page allows you to manage all discount codes defined for your customers and monitor their usage statistics.

---

## 🔍 Discount Code Monitoring

### List Features
- **Usage Tracking:** Monitor how many times each coupon has been used and its limits.
- **Validity Check:** Quickly see expired or exhausted coupons.
- **Search:** Find codes instantly via their name (e.g., `WELCOME10`).

### Table Columns
- **Code:** The string the customer enters at checkout.
- **Type:** Discount type (% or Fixed).
- **Limit:** Total usage limit and remaining count.
- **End Date:** Expiry time of the coupon.
- **Status:** Active, Inactive, or Exhausted.

---

## ⚡ Quick Actions
- Click a row to edit coupon details, minimum purchase amounts, and constraints.
- Use the **"New Coupon"** button in the top right to define new codes.
