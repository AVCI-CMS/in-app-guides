# Dictionary Management: List View

This page allows you to manage the glossary, technical terms, or brand dictionaries across the platform.

---

## 🔍 Term Oversight

### List Features
- **Category Filter:** Group terms by domain (e.g., Art, Technical, History).
- **Language Management:** Manage multi-language versions independently.
- **Search:** Quickly find terms via keyword or partial definition.

### Table Columns
- **Word/Term:** The primary concept being defined.
- **Part of Speech:** Grammatical tag (Noun, Verb, etc.).
- **Category:** Functional group of the term.
- **Status:** Current accessibility state.

---

## ⚡ Quick Actions
- Click a row to edit definition, etymology, and phonetics.
- Use the **"New Word"** button in the top right to start a new entry.
