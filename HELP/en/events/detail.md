# Event Management: Editing and Capacity

Configure activity headlines, rich text content, and capacity rules.

---

## 🛠️ Activity Configuration

### Content and Pricing
- **Title and Slug:** The main header and the URL path.
- **Rich Text Editor:** Use the Tiptap editor for primary event content.
- **Sale Price:** Configure discounts or promotional prices.

### Venue and Capacity
- **Venue:** Assign the activity to a specific location or studio.
- **Capacity Tracking:** Manually set capacity or enable automatic tracking.

### Relationships
- **Brand and Merchant:** Assign the activity to a specific brand or vendor profile.

---

## 🚦 Status Management
Set an item as **"Hidden"** to keep it accessible only via a direct link without showing it in the catalog, or **"Sold Out"** to prevent automated purchases while keeping it visible.
