# Event Management: List View

This page allows you to manage all activities, worksops, and exhibitions across the platform, including their stock and ticketing states.

---

## 🔍 Activity Oversight

### List Features
- **Capacity Tracking:** Instantly see which activities are "Sold Out" or "Low Capacity".
- **Language Filtering:** Manage multi-language versions independently.
- **Visibility Control:** Instantly see which items are Live, Hidden, or Draft.

### Table Columns
- **Cover Image:** Primary visual for the event.
- **Title:** Name of the item in the CMS.
- **Category:** Functional group of the activity.
- **Capacity:** Quantity available for purchase.
- **Status:** Current accessibility state.

---

## ⚡ Quick Actions
- Click a row to edit activity details, variant properties, or venue assignments.
- Use the **"New Event"** button in the top right to start a new entry.
