# FAQ Management: List View

This page allows you to categorize common customer questions and build a helpful Knowledge Base.

---

## 🔍 FAQ Oversight

### List Features
- **Topic Groups:** Cluster questions under Shipping, Returns, or Payments.
- **Ordering:** Move most common questions to the top for user convenience.
- **Lingual Sets:** Create different FAQ sets tailored for each supported language.

### Table Columns
- **Question:** The headline visible to users.
- **Group/Category:** Technical or functional topic of the question.
- **Date:** Update or publication time.
- **Status:** Live or Draft.

---

## ⚡ Quick Actions
- Click a row to edit the question/answer and add rich media (Links, Images, etc.).
- Use **"New Question"** in the top right to expand your library.
