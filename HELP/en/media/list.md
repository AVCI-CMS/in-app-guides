# Media Management: List View

This page allows you to manage all images, PDF documents, and media files centrally across the platform.

---

## 🔍 Media Library

### File Management
- **Module-Based Filter:** List only product images, news visuals, or user avatars.
- **Search:** Find your visuals via their file name.
- **Bulk Actions:** Select multiple files to delete or move them to a different category.

### Visual Preview
- Toggle between table or Grid view to visually inspect your files.
- **File Size and Format:** Instantly see the actual file size and format of every visual.

---

## ⚡ Quick Actions
- Drag and drop files into the **"Upload"** area in the top right to add new assets.
- Click on a visual to see detailed editing and its public URL.
