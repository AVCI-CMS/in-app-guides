# Menu Management: Links and Ordering

Add, delete, and reorder links within your selected menu using drag-and-drop.

---

## 🛠️ Menu Item Configuration

### Link Settings
- **Title:** The display text in the menu.
- **URL:** Destination path (e.g., `/about` or `https://site.com`).
- **Icon:** Visual symbol next to the menu item.
- **Order:** Numerical sequence for items.

### Creating Sub-menus
Use drag-and-drop to place an item "into" another to create **Nested** structures, essential for dropdown designs.

---

## 🚦 Activation
Changes made to menus are saved instantly, and the navigation structure on your app/website is updated accordingly.
