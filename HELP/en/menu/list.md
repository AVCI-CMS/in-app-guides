# Menu Management: List View

This page allows you to manage navigation structures for different areas of your website or app (Header, Footer, Mobile, etc.).

---

## 🔍 Navigation Oversight

### Menu Categories
- **Main Menu (Header):** Basic links at the top of the interface.
- **Footer Navigation:** Auxiliary link groups at the bottom.
- **Mobile Links:** Special menus visible only in mobile apps.

### Table Columns
- **Menu Name:** Title of the navigation group.
- **Slug:** Technical key (e.g., `main-nav`).
- **Location:** Where the menu appears.
- **Status:** Active or inactive state.

---

## ⚡ Quick Actions
- Click a row to edit and reorder links within the menu.
- Use the **"New Menu"** button in the top right to define navigation for a different area.
