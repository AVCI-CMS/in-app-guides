# Newsletter Management: List View

This page allows you to manage all email subscribers and mailing lists for your marketing campaigns.

---

## 🔍 Subscriber Oversight

### List Features
- **Verification Filter:** See active subscribers who have verified their emails.
- **Bulk Actions:** Pause or remove multiple subscribers simultaneously.
- **Export:** Download the subscriber list as PDF, CSV, or Excel for external tools (e.g., Mailchimp).

### Table Columns
- **Email:** Registered address of the subscriber.
- **Name:** (If provided) Name of the subscriber.
- **Sign-up Date:** Joined time.
- **Status:** Active, Pending, or Unsubscribed.

---

## ⚡ Quick Actions
- Click a row for individual profile editing.
- **Manual Entry:** Use the top-right button to manually add an email to the list.
