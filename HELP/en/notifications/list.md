# Notification Management: List View

This page allows you to monitor and manage all system alerts and announcements sent to users or staff.

---

## 🔍 Notification Oversight

### List Features
- **Category Filter:** Separate order notifications, system alerts, or marketing announcements.
- **Channel Tracking:** Monitor which channel (Push, Email, SMS) the notification was sent through.
- **Timing Overlay:** Monitor creation and expiration dates for your notifications.

### Table Columns
- **Title/Message:** Brief alert text for the user.
- **Category:** Functional group of the notification (e.g., Order Update).
- **Read Status:** Monitor if the user has read or seen the notification.
- **Date:** Time the notification was sent.

---

## ⚡ Quick Actions
- Click a row to see detailed notification metadata and content.
- Use **"New Announcement"** to send bulk notifications to all users or a specific group.
