# Organization Management: List View

This page allows you to manage corporate members, NGOs, and business groups across the platform.

---

## 🔍 Corporate Oversight

### List Features
- **Entity Type Filter:** Distinguish between PLC, LLC, or sole proprietorships.
- **Ownership Control:** Monitor which user manages which organization.
- **Search:** Quickly access entities via their corporate or trading name.

### Table Columns
- **Logo:** Visual branding of the entity.
- **Organization Name:** Primary trading name.
- **Legal Name:** Official corporate name.
- **Website:** External link address.
- **Status:** Current visibility state.

---

## ⚡ Quick Actions
- Click a row to edit legal documents, bank accounts, or team structures.
- Use the **"New Organization"** button in the top right to start a new entry.
