# Page Management: Editing and Sections

Configure headlines, rich text content, and custom page sections.

---

## 🛠️ Page Configuration

### Content and SEO
- **Title and Slug:** The main header and the URL path.
- **Rich Text Editor:** Use the Tiptap editor for primary page content.
- **SEO Panel:** Define meta titles, descriptions, and share images for search motors.

### Modular Sections
Add or reorder modular sections (e.g., Hero, Gallery, FAQ) to build complex landing pages without coding.

---

## 🚦 Visibility
Set a page as **"Hidden"** to keep it accessible only via a direct link (e.g., for specific marketing campaigns) without showing it in navigation menus or footers.
