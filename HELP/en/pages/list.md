# Page Management: List View

This page allows you to manage all static and dynamic pages across the platform, including corporate information and legal documents.

---

## 🔍 Content Oversight

### List Features
- **Group Filtering:** Organize pages by type (e.g., Legal, About, Marketing).
- **Multi-Language Management:** Switch languages to edit translations.
- **Visibility Control:** Instantly see which pages are Live, Hidden, or Draft.

### Table Columns
- **Title:** Header of the page in the CMS.
- **Slug:** Technical key (e.g., `/about`).
- **Category:** Functional group of the page.
- **Status:** Current accessibility state.

---

## ⚡ Quick Actions
- Click a row to edit page content, layout sections, or SEO metadata.
- Use the **"New Page"** button in the top right to create a new entry.
