# Place Management: Editing and Logistics

Configure physical capabilities, weekly schedules, and map locations.

---

## 🛠️ Venue Profile Configuration

### Logistics and Capacity
- **Capacity Limits:** Minimum and maximum number of people allowed simultaneously.
- **Working Hours:** Set opening and closing times for each day of the week.
- **Facilities:** Add features like "Parking available" or "Wheelchair accessible" in the description.

### Location and Media
- **Map Coordinates:** Enter coordinates (`lat`, `lng`) or select from the map to set the exact location.
- **Gallery Integration:** Upload high-resolution photos of the interior and exterior to help guests recognize the venue.

---

## 🚦 Event Linking and Deletion
Venues are directly linked to [Event Management](./events/detail.md).
**Important:** When a venue is deleted, any active events scheduled at that venue may be affected. Check linked records before proceeding.
