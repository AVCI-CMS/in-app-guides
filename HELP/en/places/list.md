# Place Management: List View

This page allows you to manage physical venues, workshops, and locations across the platform.

---

## 🔍 Location Oversight

### List Features
- **Area Filter:** Group venues by district or neighborhood.
- **Capacity Monitoring:** View maximum visitor limits for event planning.
- **Search:** Quickly access venues via their name or address.

### Table Columns
- **Logo:** Visual branding of the venue.
- **Venue Name:** Trading name.
- **District/Neighborhood:** Area of the location.
- **Capacity:** Maximum number of participants.
- **Status:** Current visibility state.

---

## ⚡ Quick Actions
- Click a row to edit venue profiles, gallery images, or operational hours.
- Use the **"New Place"** button in the top right to start a new entry.
