# Project Management: Editing and Team

Configure the technical details, the team behind the project, and all visual assets.

---

## 🛠️ Project Profile Configuration

### Story and Content
- **Description:** A rich text detailing the project's purpose, process, and technical specs.
- **Gallery:** High-resolution photos and plans belonging to the project.
- **Links:** Live versions of the project or Behance/GitHub page links.

### Team and Participants
- **Team Groups:** Create groups like "Design Team" or "Implementation Team".
- **Member Assignment:** Define the name and role of every member (e.g., Lead Architect, Project Manager).

### Social and SEO
- **Social Media:** Link specific social channels to the project.
- **SEO Panel:** Define how the project appears in search motores.

---

## 🚦 Visibility
Once a project is set to **"Active"**, it becomes discoverable on the public portfolio page of the website.
