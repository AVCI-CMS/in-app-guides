# Project Management: List View

This page allows you to manage architectural, artistic, or commercial projects in your portfolio.

---

## 🔍 Portfolio Oversight

### List Features
- **Year Filter:** Quickly list projects by their completion year.
- **Category Filter:** Separate between design, application, or concept projects.
- **Archiving:** Move completed projects to an "Archive" state for reference sections.

### Table Columns
- **Project Name:** Title of the project.
- **Year:** Date of completion or launch.
- **Category:** Domain or type of the project.
- **Status:** Current visibility state.

---

## ⚡ Quick Actions
- Click a row to edit project details, team lists, and gallery images.
- Use the **"New Project"** button in the top right to start a new entry.
