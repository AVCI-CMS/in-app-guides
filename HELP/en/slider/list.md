# Slider Management: List View

This page allows you to manage carousel visuals (Sliders) on your website's home page or your mobile application's showcase.

---

## 🔍 Showcase Oversight

### List Features
- **Slider Types:** Distinguish between main page (Hero), announcement bars, or product showcases.
- **Active Status:** Instantly see which slider is live.
- **Slide Count:** Monitor the number of visuals within each dynamic slider.

### Table Columns
- **Slider Title:** Display name in the management panel.
- **Slug:** Technical key used by developers.
- **Type:** Hero, Banner, or Custom placement type.
- **Status:** Live or Draft state.

---

## ⚡ Quick Actions
- Click a row to add, reorder, and edit visuals (Slides) within the slider.
- Use the **"New Slider"** button in the top right to define a different marketing area.
